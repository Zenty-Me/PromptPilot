# 2026-09-15

## 功能：完善「添加网页 AI」+ 可配置快捷键（v2.0.0 → v2.1.0）

### 决策（用户确认）
1. 自定义站点采用**动态注册内容脚本**（`optional_host_permissions` + `chrome.scripting.registerContentScripts`），而非一次性 `<all_urls>`，也非纯 activeTab 临时注入。
2. 快捷键：页面内全可配（设置页录制）+ 浏览器全局键只做展示与跳转引导。
3. 站点管理能力只做「编辑 + 启用开关」，未做选择器在线测试、导入导出含站点、内置站点管理（用户明确只选了这一项）。

### 关键实现
- `manifest.json`：加 `optional_host_permissions: ["http://*/*","https://*/*"]`；content_scripts 追加 `shared/defaults.js` 与 `content/shortcuts.js`。
- `shared/defaults.js`：新增 `SHORTCUT_META`（5 个动作）、`CONTENT_SCRIPT_FILES`、`CONTENT_SCRIPT_ID_PREFIX`。
- `shared/utils.js`：新增快捷键解析/匹配/格式化/校验 + 网址规整三件套。
- `background.js`：重写为「命令转发 + 站点脚本注册中枢」，`importScripts` 引入 shared 层。
- `content/shortcuts.js`（新增）：页面内快捷键分发。
- `content/panel.js`：导出 togglePanel/closePanel/toggleBall/injectRecent/submitCurrent/isPanelOpen，加 `showNotice` 与 `showBall` 持久化。
- `content/inject.js`：站点匹配按 pattern 长度排序、`enabled` 过滤、注入支持 replace/append 且 contenteditable 有兜底。
- `popup/`：站点就地编辑 + 开关 + 未授权标记；设置页新增快捷键分区（录制/重置/全局键引导）。

### 两个必须记住的坑
1. **全局命令与页面内快捷键同组合会互相抵消**：Chrome 先捕获 → background 转发 `toggle_panel` 打开面板，内容脚本再处理一次就关掉了。解法：background 把 `chrome.commands.getAll()` 的有效组合写入 `storage.globalShortcuts`，内容脚本命中这些组合时直接放行。
2. **权限申请必须在 popup 做**（有用户手势）。service worker 里 `chrome.permissions.request` 拿不到手势上下文；background 只负责「已授权才注册」，绝不弹框。

### 验证
- `npm test`：4 个套件 57 项断言全过 + dragtest 回归通过。
  - 其中 `tests/consistency.test.js` 是新增的静态契约检查（DOM id / data 属性 / 消息类型 / 跨模块导出 / manifest 与 CONTENT_SCRIPT_FILES 一致），专门防多文件重构后的幽灵引用。
- 未做真机 Chrome 加载验证（无浏览器环境），动态注册与权限弹窗链路属**未验证项**。

### 环境备注
本机 Bash 工具 PATH 损坏（`dirname: command not found`），需在命令前加 `export PATH="/usr/bin:/bin:$PATH"`；PowerShell 工具 stdout 捕获为空，不可用。

## 视觉重构：去「AI 味」（同一天，v2.1.0 之后）

### 方向（用户三选一确认）
1. 配色：**深色优先 + 中性石墨灰阶**（非 Catppuccin）
2. 强调色：**靛蓝 `#4F6BED`**，且**用量压到很低**——只标记状态（选中/聚焦/主按钮），不做装饰
3. 范围：popup 弹窗 + 页面内悬浮球/面板一起改

### 判定「AI 味」的具体特征（可复用的检查清单）
- Catppuccin 配色（`#1e1e2e`/`#313244`/`#89b4fa` 全家桶）—— 一眼可辨的 AI 默认答案
- 渐变 + 同色系光晕 `box-shadow`（悬浮球原来是 `linear-gradient(135deg,#89b4fa,#74c7ec)` + 光晕 + 2.5s 脉冲动画）
- 圆角/字号失控：圆角 7 种混用、字号 9~14px 六级（9px 不可读）
- 大模糊阴影 `0 8px 32px`
- 「hover 万物变强调色」的廉价交互
- 文本符号与图标混搭（`☰` `⊟` `▼` `&times;` 混在 lucide 图标里）
- AI 造 logo 套路：带 `rotate(-8deg)` 和伪元素尾巴的小方块

### 做法
- `popup/popup.css` 整体重写：建立设计令牌（灰阶/强调/语义/形状/阴影/字号），圆角收敛到 3-5-8-10，字号 10-11-12-13-14，阴影分 --sh-sm/md/lg 三层。
- `content/panel-styles.js`（**新增**）：把 panel.js 里 13KB 的内联 CSS 字符串抽出来；悬浮球改实心 accent + 细阴影、去掉渐变与脉冲；所有规则保留 `!important` 与 `pp-`/`pi-` 前缀。
- `content/panel.js`：删掉 BALL_CSS/PANEL_CSS 定义，改为引用 `PP_BALL_CSS`/`PP_PANEL_CSS`/`PP_NOTICE_CSS`/`PP_BALL_SIZE`，从 948 行精简到 948-78 行量级。
- 图标统一 lucide：`command`（品牌）、`list`/`layers`（视图）、`x`（关闭）、`chevron-down`（折叠）。

### 顺手修掉的真实 bug
1. **录制提示条一直显示**：`app.js` 用 `classList.add("hidden")` 控制 `.shortcut-capture`，但 CSS 里根本没有 `.shortcut-capture.hidden{display:none}` 规则 → 提示条常驻弹窗顶部。已在重写时补上。
2. **`--pi-inset` 配色漂移**：新写的 theme 测试第一轮就抓到 panel 用 `#16171a`、popup 用 `#101114`。已统一。

### 新增测试守卫
- `tests/theme.test.js`（6 项）：popup 与页面面板**配色同源**（5 组 token × 深/浅）、Catppuccin 色值零残留、panel.js 不再内联 CSS、悬浮球直径单一定义。
- `tests/consistency.test.js` 补 2 项：manifest 声明的脚本文件必须真实存在；**`panel-styles.js` 必须先于 `panel.js`**（panel.js 是 IIFE，顶层就读 `PP_BALL_SIZE`，顺序颠倒真机崩，但 jsdom 测试用 stub 顶替 `PromptPanel` 不会暴露 → 典型的"假绿"）。

### 教训
当初 shortcuts-dom 测试全绿，看似覆盖充分，实际因为它 **stub 掉了 `PromptPanel`、根本没加载 panel.js**。以后凡是「加载顺序」类契约，必须靠静态检查守，不能指望行为测试。
